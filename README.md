# 钩织工作台

一个用于整理钩织任务、花样、作品和线材的个人网页工作台。页面可在电脑、平板和手机浏览器中使用，数据保存在当前浏览器中。

> 这里是项目说明的初稿。你可以继续补充自己的介绍、截图、计划和联系方式。

## 功能

- **任务计划**：新增、编辑、删除任务；按未开始、进行中、已超期、已完成分类；更改状态或编辑任务时可撤销；完成任务时可选择加入作品记录。
- **加减针计算**：根据起始针数、结束针数和总行数，生成尽量均匀的逐行加减针建议。
- **花样参考**：记录花样名称、描述、标签、适用线材、参考来源和图片；支持搜索、编辑和删除。
- **作品记录**：记录作品图解、线材、钩针型号、设计思路、钩织要点和图片；支持编辑和删除。
- **线材管理**：记录线材信息和库存；可以调整库存数量、编辑和删除记录。
- **数据导入 / 导出**：导出包含图片的 JSON 备份，或导出方便查看的 CSV 表格；可以从 JSON 备份恢复数据。
- **响应式布局**：针对手机、平板和电脑屏幕调整页面布局。

## 如何使用

### 在线使用

打开上方的 GitHub Pages 链接即可。第一次使用时可以添加自己的记录，也可以先试用示例内容。

### 在电脑本地打开

下载或克隆此项目后，在文件夹中打开 `index.html`。如果浏览器限制了本地文件的部分功能，可以使用 VS Code 的 Live Server 等本地网页预览工具打开。

### 在手机上使用

打开 GitHub Pages 在线链接即可使用。手机和电脑的浏览器数据彼此独立；如果要在设备间迁移记录，请在原设备导出 JSON，再在另一设备的数据导入页面选择该文件。

## 数据与隐私

- 任务、花样、作品、线材和图片保存在当前浏览器的本地存储中。
- 网页部署到 GitHub Pages 后，其他访问者可以打开网页，但看不到你保存在自己浏览器里的记录。
- 不同浏览器、设备或浏览器的隐私模式使用各自独立的数据空间。清除浏览器网站数据可能会删除记录，请定期导出 JSON 备份。
- CSV 文件适合查看和整理，不包含图片，也不能用于恢复数据；跨设备恢复请使用 JSON 备份。

## GitHub Pages 部署

1. 将 `index.html`、`style.css`、`app.js` 和 `README.md` 放在 GitHub 仓库的根目录。
2. 在仓库的 **Settings → Pages** 中选择从分支部署。
3. 选择 `main` 分支和 `/(root)` 目录并保存。
4. 等待 GitHub Pages 完成发布，再打开页面顶部显示的站点链接。
5. 更新网页时，将有改动的文件提交并推送到仓库；例如只改了 `app.js`，就只需更新该文件。
